# 基于 SpringBoot + Vue  的智慧药房系统

用户端 · 药店端 · 员工端 · 管理员端 | 药品管理 · 订单交易 · 库存预警 · 采购物流 · 积分商城 · 社区互动 · 数据统计

本项目是一套面向连锁药房/单体药店的现代化智慧药房管理平台，采用前后端分离架构，覆盖**管理员、药店、员工、用户**四类核心角色。系统围绕"药品管理、订单交易、库存预警、采购物流、会员积分、社区互动、数据统计"等核心业务设计，支持从药品入库、门店销售、在线购药、会员积分兑换，到采购管理、库存预警、保质期管理、员工考勤薪资、社区问答的全链路数字化运营，构建"人—药—店—单—库"一体化的智慧药房管理平台。

## 核心特性

- **多药店连锁管理**：支持平台下多药店入驻与管理，管理员可维护药店信息（药店名称、地址、负责人、营业状态、资质信息），药店端独立管理本店业务，支持跨店数据汇总与单店独立运营。
- **药品全生命周期管理**：支持药品信息管理（药品名称、通用名、规格、剂型、生产厂家、批准文号、药品类型、处方药/非处方药标识、用法用量、禁忌说明），支持药品分类管理、药品上下架、药品收藏功能，实现药品从采购入库到销售出库的全流程追溯。
- **在线购药与订单管理**：用户可在线浏览药品、加入购物车、提交订单、在线支付，支持收货地址管理；药店/员工端处理订单（接单/发货/完成/取消），支持订单状态跟踪、订单评价、订单模板快速下单；管理员可全局查看订单数据。
- **库存预警与保质期管理**：实时监控药店库存，支持库存上下限预警、库存不足自动提醒；药品保质期预警，临期药品自动标记提醒，支持近效期优先出库策略，降低药品过期损耗。
- **采购与物流管理**：支持药品采购流程（采购申请→采购订单→供应商发货→物流跟踪→入库验收），支持供应商管理（供应商名称、联系人、资质、供应药品范围），采购记录全程留痕，支持采购物流实时跟踪。
- **会员积分体系**：用户购药获得积分，积分可用于兑换商品（积分商城）或抵扣金额；支持会员积分管理、积分兑换记录、商品积分配置；药店可查看本店会员积分数据，管理员可全局统计积分发放与兑换情况。
- **社区互动模块**：用户可发布帖子（用药咨询/健康分享/评价反馈），其他用户可回复互动，管理员/药店可管理帖子与回复，构建药房社区生态。
- **员工考勤与薪资**：支持员工考勤打卡（上下班打卡、请假申请）、考勤统计；支持薪资发放管理（基本工资、绩效、奖金、扣款），员工可查看个人考勤与薪资明细，药店可管理本店员工薪资，管理员可全局查看薪资发放记录。

## 功能模块概览

## 管理员端

管理员为平台最高权限角色，负责全局配置与多药店监管：

### 账号与组织架构

- **用户管理**：管理注册用户，包括用户ID、用户名、手机号、注册时间、账户状态，支持用户信息查询、账户冻结/解冻。
- **员工管理**：管理各药店员工，包括员工工号、姓名、所属药店、岗位、联系方式、入职时间、账户状态，支持员工增删改查。
- **药店管理**：管理入驻药店，包括药店名称、地址、负责人、联系电话、营业状态、资质信息、营业时间，支持药店增删改查与审核。
- **供应商管理**：管理药品供应商，包括供应商名称、联系人、联系电话、地址、资质信息、供应药品范围、合作状态，支持供应商增删改查。

### 药品与库存

- **药品管理**：管理全平台药品库，包括药品名称、通用名、规格、剂型、生产厂家、批准文号、药品类型、处方药标识、用法用量、禁忌说明、上下架状态，支持药品增删改查与批量导入。
- **药品类型**：管理药品分类字典，包括类型名称（如中成药/西药/保健品/医疗器械等）、父级分类、排序，支持多级分类管理。
- **药店库存**：查看各药店的药品库存情况，包括药品名称、库存数量、库存预警状态，支持跨店库存查询与调拨记录查看。
- **库存预警**：查看全平台库存预警列表，包括药品名称、所属药店、当前库存、预警阈值、预警类型（库存不足/库存过剩），支持预警处理与通知。
- **保质期预警**：查看全平台临期药品列表，包括药品名称、所属药店、生产日期、有效期至、剩余天数，支持近效期药品标记与处理提醒。
- **药品收藏**：查看用户药品收藏数据，包括用户、收藏药品、收藏时间，支持收藏统计分析。

### 采购与物流

- **药品采购**：查看全平台采购订单，包括采购单号、采购药店、供应商、采购药品、采购数量、采购金额、采购状态，支持采购订单审核。
- **采购记录**：查看历史采购记录，支持按药店/供应商/时间筛选，支持采购报表导出。
- **采购物流**：查看采购物流跟踪信息，包括物流单号、物流公司、物流状态、预计到达时间，支持物流异常提醒。

### 订单与交易

- **订单管理**：查看全平台订单，包括订单号、下单用户、订单药品、订单金额、支付状态、订单状态、下单时间，支持订单详情查看、订单筛选与导出。
- **订单评价**：查看用户对订单的评价，包括评价内容、评分、评价时间、关联订单，支持评价审核与违规评价处理。
- **订单模板**：管理订单模板，预设常用购药清单模板，支持用户快速下单。

### 会员与积分

- **药店会员**：查看各药店会员数据，包括会员用户、所属药店、会员等级、积分余额、注册时间。
- **会员积分**：查看用户积分明细，包括积分获取记录（购药赠送）、积分消耗记录（兑换/抵扣）、积分余额，支持积分调整。
- **商品积分**：管理积分商城商品，包括商品名称、所需积分、商品库存、兑换规则、上下架状态，支持积分商品增删改查。
- **积分兑换**：查看用户积分兑换记录，包括兑换用户、兑换商品、消耗积分、兑换时间、兑换状态，支持兑换订单管理。

### 社区与沟通

- **贴子模块**：管理帖子分类，包括分类名称、排序、状态，支持分类增删改查。
- **贴子列表**：查看全平台帖子，包括帖子标题、内容、发帖人、发帖时间、回复数、点赞数、状态，支持帖子审核、置顶、删除。
- **消息回复**：查看用户对帖子的回复，包括回复内容、回复人、回复时间，支持回复审核与违规回复处理。
- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（活动通知/系统维护/促销信息）、发布时间、置顶状态、可见范围，支持公告编辑与删除。

### 财务与人事

- **薪资发放**：查看全平台员工薪资发放记录，包括员工姓名、所属药店、发放月份、基本工资、绩效、奖金、扣款、实发金额、发放状态，支持薪资审核与发放。
- **员工考勤**：查看全平台员工考勤记录，包括员工姓名、所属药店、打卡时间、考勤状态（正常/迟到/早退/缺勤/请假），支持考勤统计与报表导出。

### 数据与运维

- **数据统计**：综合数据看板，展示核心运营指标（今日订单数/今日销售额/活跃用户数/库存预警数/临期药品数），支持销售趋势、药品销量排行、药店业绩对比、会员增长分析、采购支出统计、帖子活跃度等多维度图表展示，支持报表导出。
- **问题检查**：系统健康检查与问题诊断，包括数据一致性检查、库存异常检测、订单异常检测、日志查看，支持问题记录与处理跟踪。
- **用户地址**：查看用户收货地址数据，包括用户、收货人、联系电话、收货地址、默认地址标识，支持地址数据管理。

## 药店端

药店为门店运营方，负责本店业务管理与日常运营：

### 账号与门店

- **药店注册登录**：支持药店账号注册与登录，注册需提交药店基本信息与资质，管理员审核通过后激活账号。
- **密码修改**：支持药店自主修改登录密码，保障账户安全。
- **药店信息**：查看与编辑本店基本信息，包括药店名称、地址、负责人、联系电话、营业时间、药店简介、门店图片，支持资质文件上传。

### 药品与库存

- **药品管理**：管理本店药品，包括药品上下架、本店售价设置、库存管理，支持药品搜索与筛选。
- **药店库存**：查看本店药品库存，包括药品名称、库存数量、库存预警状态，支持库存盘点与库存调整。
- **库存预警**：查看本店库存预警列表，包括库存不足药品、库存过剩药品，支持预警处理与补货提醒。
- **保质期预警**：查看本店临期药品列表，包括药品名称、有效期至、剩余天数，支持近效期药品促销处理与优先出库。
- **问题检查**：本店数据健康检查，包括库存异常、订单异常、数据不一致检测，支持问题记录与处理。

### 采购与物流

- **药品采购**：发起本店药品采购，选择供应商与采购药品，填写采购数量，生成采购订单，支持采购订单提交与状态跟踪。
- **采购供应**：查看本店供应商列表，包括供应商名称、联系人、供应药品，支持供应商选择与采购下单。
- **采购记录**：查看本店历史采购记录，支持按时间/供应商/药品筛选，支持采购报表导出。
- **采购物流**：查看本店采购物流跟踪，包括物流单号、物流状态、预计到达时间，支持物流异常反馈。

### 订单与交易

- **订单管理**：查看本店订单，包括待接单、待发货、配送中、已完成、已取消订单，支持订单处理（接单/发货/完成/取消）、订单详情查看、订单搜索。
- **订单评价**：查看用户对本店订单的评价，包括评价内容、评分、评价时间，支持评价回复与评价管理。

### 会员与积分

- **药店会员**：查看本店会员列表，包括会员用户、会员等级、积分余额、注册时间、最近消费时间，支持会员信息查询。
- **会员积分**：查看本店会员积分明细，包括积分获取与消耗记录，支持积分调整（需管理员审核）。

### 人事与财务

- **员工管理**：管理本店员工，包括员工增删改查、岗位分配、权限配置，支持员工账户激活/冻结。
- **员工考勤**：查看本店员工考勤记录，包括打卡时间、考勤状态，支持考勤统计与报表导出。
- **员工薪资**：管理本店员工薪资，包括薪资录入（基本工资、绩效、奖金、扣款）、薪资审核、薪资发放，支持薪资明细查看。
- **药店收入支出数据统计**：查看本店经营数据统计，包括收入统计（药品销售、其他收入）、支出统计（采购支出、运营成本）、利润分析、销售趋势图表，支持按日/周/月筛选与报表导出。

## 员工端

员工为门店执行层，负责日常运营与订单处理：

### 账号与个人

- **员工登录**：支持工号+密码登录，首次登录由药店管理员分配账号，支持找回密码。
- **密码修改**：支持员工自主修改登录密码，保障账户安全。
- **我的信息**：查看与编辑个人基本信息，包括工号、姓名、所属药店、岗位、联系方式，支持头像上传。

### 药品与库存

- **药品管理**：查看本店药品信息，包括药品详情、库存数量、售价，支持药品搜索。
- **药店库存**：查看本店药品库存，支持库存查询与库存盘点操作。
- **库存预警**：查看本店库存预警提醒，包括库存不足药品，支持补货提醒。
- **保质期预警**：查看本店临期药品提醒，支持近效期药品标记与处理。
- **问题检查**：查看本店数据异常提醒，支持问题上报。

### 采购与物流

- **药品采购**：发起药品采购申请，选择供应商与采购药品，填写采购数量，提交采购申请供药店审核。
- **采购物流**：查看采购物流跟踪信息，包括物流状态、预计到达时间。

### 订单与交易

- **订单管理**：查看本店订单，处理待接单、待发货订单，支持订单状态更新（发货/完成）、订单详情查看。
- **订单评价**：查看用户订单评价，支持评价回复。

### 会员

- **药店会员**：查看本店会员信息，支持会员查询。

### 人事

- **我的考勤**：查看个人考勤记录，包括打卡时间、考勤状态，支持上下班打卡与请假申请。
- **我的薪资**：查看个人薪资明细，包括基本工资、绩效、奖金、扣款、实发金额、发放月份，支持薪资历史查看。

## 用户端

用户为购药消费者，负责在线购药、积分兑换与社区互动：

### 账号与个人

- **注册登录**：支持手机号+验证码注册与登录，支持密码登录，支持找回密码。
- **密码修改**：支持用户自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括用户名、手机号、头像、性别、生日，支持信息修改。
- **收货地址**：管理收货地址，包括新增、编辑、删除收货地址，设置默认地址，支持地址簿管理。

### 购药与订单

- **我的订单**：查看个人订单列表，包括待支付、待发货、配送中、已完成、已取消订单，支持订单详情查看、订单搜索、订单取消（待支付/待发货状态）。
- **在线支付**：支持订单在线支付，集成微信支付/支付宝等支付方式，支持支付状态实时回调。
- **订单评价**：对已完成订单进行评价，包括评分（1-5星）、评价内容、评价图片，支持评价提交与修改。
- **药品收藏**：收藏感兴趣的药品，查看收藏列表，支持取消收藏与快速下单。

### 积分与兑换

- **积分兑换**：浏览积分商城，查看可兑换商品与所需积分，支持积分兑换下单。
- **兑换记录**：查看个人积分兑换记录，包括兑换商品、消耗积分、兑换时间、兑换状态（待发货/已完成）。

### 社区与沟通

- **我的贴子**：发布与管理个人帖子，包括发帖（用药咨询/健康分享）、查看帖子列表、编辑/删除帖子、查看帖子回复。
- **消息回复**：查看他人对个人帖子的回复，支持回复他人，形成社区互动。
